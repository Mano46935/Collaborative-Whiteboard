# Collaborative Whiteboard

A real-time collaborative whiteboard application that allows multiple users to draw together on a shared canvas. The project uses WebSockets for live synchronization and React for the frontend.

## Features

* Real-time collaborative drawing
* Live cursor tracking
* Multiple users on the same board
* User colors and identification
* Responsive canvas

## Tech Stack

* React
* Socket.IO
* Node.js
* Express

## Learning Goals

This project was built to learn:

* Real-time communication with Socket.IO
* React state management
* Collaborative application architecture
* Canvas drawing techniques
